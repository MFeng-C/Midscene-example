# iOS 纯录制业务流程自动化测试 - 问题与解决方案

**日期**: 2026-06-29
**测试脚本**: `test_pure_recording_ios.py`
**测试流程**: 客户纯录制业务流程

---

## 一、问题描述

### 1.1 问题现象

在执行 Step 6（点击"开始直播"按钮）时，Appium 无法定位到 iOS ReplayKit 录屏弹窗上的"开始直播"按钮，导致测试失败。

**错误日志**:
```
ClassChain 失败: NoSuchElementError: An element could not be located on the page
Predicate 失败: NoSuchElementError: An element could not be located on the page
WebView 按钮文本为空，无法通过文字匹配
```

### 1.2 问题根因

**ReplayKit 广播选择器（Broadcast Picker Sheet）特性**：
- 这不是标准 SpringBoard Alert/ActionSheet，而是系统独立进程弹窗
- iOS 系统对录屏弹窗做了无障碍隔离（Accessibility Isolation）
- WDA/XCUITest 无法穿透该弹窗的无障碍隔离层
- 即使开启 `respectSystemAlerts: true`，WDA 也只能读取被测 App 或标准系统弹窗的 UI 树
- 按钮元素存在，但 label 属性为空，文本渲染在 canvas/CGImageView 上

---

## 二、尝试过的解决方案

### 2.1 配置优化

| 方案 | 配置项 | 结果 |
|------|--------|------|
| `autoAcceptAlerts` | True | ❌ 无效，ReplayKit 弹窗不属于标准 Alert |
| `respectSystemAlerts` | True | ❌ 无效，无法穿透隔离层 |

### 2.2 元素定位方式

| 方案 | 定位方式 | 结果 |
|------|----------|------|
| IOS_CLASS_CHAIN | `**/XCUIElementTypeButton[\`label == "开始直播"\`]` | ❌ 找不到元素 |
| NSPredicate | `label == "开始直播" AND type == "XCUIElementTypeButton"` | ❌ 找不到元素 |
| WebView 切换 | 遍历所有 button 元素 | ❌ 按钮文本为空 |
| mobile: alert | `{"action": "accept"}` | ❌ 识别不到 alert |

---

## 三、最终解决方案

### 3.1 坐标点击（百分比定位）

**核心思路**：既然无法通过元素定位，则根据截图分析按钮位置，使用百分比坐标点击。

**按钮位置分析**：
- 截图尺寸：1707 x 960 px
- 按钮横向占比：50%（弹窗居中，文字水平居中）
- 按钮纵向占比：67%

**实现代码**:
```python
def step6_click_start_live(driver, cycle_num):
    """Step 6: 点击'开始直播' - 使用坐标点击"""

    # 方案1-2: 尝试 Class Chain 和 Predicate（兜底意识）
    try:
        btn = driver.find_element(AppiumBy.IOS_CLASS_CHAIN,
            '**/XCUIElementTypeButton[`label == "开始直播"`]')
        if btn.is_displayed():
            btn.click()
            return True
    except:
        pass

    # 方案3: 坐标点击（百分比定位，适配所有iPhone竖屏）
    window_size = driver.get_window_size()
    w = window_size["width"]
    h = window_size["height"]
    tap_x = int(w * 0.5)   # 50%
    tap_y = int(h * 0.67)  # 67%
    driver.tap([(tap_x, tap_y)])
```

### 3.2 方案优势

| 优势 | 说明 |
|------|------|
| 跨设备兼容 | 百分比定位适配所有 iPhone 竖屏分辨率 |
| 稳定可靠 | 不依赖元素属性，避免页面结构变化影响 |
| 性能优秀 | 无需遍历查找，直接计算坐标点击 |

## 五、注意事项

1. **设备兼容性**：百分比坐标方案适用于 iPhone 竖屏，分辨率适配范围 736x414 ~ 1290x2796
2. **坐标微调**：如果按钮位置有偏差，可微调 `tap_y` 百分比值（当前 67%）
3. **系统弹窗**：ReplayKit 弹窗属于系统级 UI，任何元素定位方案都可能失效，坐标点击是最可靠的兜底方案
4. **权限预授权**（备选方案）：iOS14+ 可尝试 `mobile: setPermissions` 预授权录屏权限，彻底绕过弹窗
