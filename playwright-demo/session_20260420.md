## 关键修复点

### 窗口识别
- **问题**: pywinauto win32 backend 连接到 Chrome 窗口而非 JDualRecord
- **解决**: 使用 pygetwindow 枚举所有窗口，过滤条件 `title == '双录系统' and left > 0`

### 按钮点击
- **问题**: "人工双录"按钮坐标点击失败
- **解决**: 截图调试 + 多候选位置 + 坐标点击
