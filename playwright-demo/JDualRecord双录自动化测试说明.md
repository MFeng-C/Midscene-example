## 一、项目背景

JDualRecord 双录系统是我司临柜业务的核心录制工具，需支持**人工双录**和**AI双录**两种模式，覆盖**发起双录**和**临柜双录**两条业务线。

传统人工测试存在以下问题：
- 测试耗时长（每场景约 10~15 分钟）
- 重复执行容易遗漏步骤
- 测试结果依赖测试人员经验，难以形成标准化报告

为此，我们开发了自动化测试脚本，实现双录全流程的无人值守测试。

## 三、自动化测试流程

每条脚本均完整覆盖以下步骤：

```
1. 浏览器登录系统
2. 进入双录页面（发起双录 / 临柜双录）
3. 填写客户信息
4. 填写产品信息
5. 选择录制类型（现场）
6. 点击开始录制
7. 处理系统协议弹窗（自动按键）
8. 连接 JDualRecord 插件窗口
9. 执行双录操作：
   - 选择双录模式（人工/AI）
   - 点击开始双录
   - 等待倒计时（3秒）
   - 点击终止双录
   - 确认放弃录制
10. 关闭插件窗口，测试完成
```

## 四、技术方案

### 4.1 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 浏览器自动化 | Playwright | 跨浏览器控制，稳定可靠 |
| 窗口控制 | win32api | Windows 原生 API 操作插件窗口 |
| 坐标点击 | pyautogui | 基于截图分析精确定位按钮 |
| 图像识别 | OpenCV | 分析截图，识别按钮区域 |

### 4.2 核心难点解决方案

**难点一：插件窗口识别**
- 通过 Windows API 枚举所有窗口，按标题关键字"双录系统"精确定位
- 窗口激活后进行最大化，确保按钮在可视区域

**难点二：协议弹窗处理**
- 弹窗弹出后自动按 `Tab` 键切换焦点，再按 `Enter` 确认
- 无需计算坐标，零失误

**难点三：按钮精确定位**
- 通过 OpenCV 分析截图中的蓝色按钮区域
- 结合窗口偏移量计算绝对屏幕坐标
- 误差控制在 5 像素以内
