## 关键发现

1. **App启动方式**: 需要通过点击桌面图标【智能双录】启动，不能用adb shell am start直接启动Activity
2. **输入框定位**: App使用H5/WebView元素，resourceId为`van-field-4-input`等
3. **登录按钮定位**: `className="android.widget.Button", text="登录"`
4. **数字键盘问题**: 输入验证码后数字键盘保持显示，需要按返回键关闭后才能点击登录按钮
5. **清空输入框**: 使用`clear_text()`和`set_text()`组合

## 技术要点

```python
# 清空并输入文本
def clear_and_set_text(d, element, text):
    element.click()
    time.sleep(0.3)
    element.clear_text()
    time.sleep(0.2)
    element.set_text(text)

# 关闭数字键盘
d.press("back")
time.sleep(1)

# 点击登录按钮
login_btn = d(className="android.widget.Button", text="登录")
if login_btn.exists(timeout=5):
    login_btn.click()
```
