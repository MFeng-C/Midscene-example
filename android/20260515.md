# 2026-05-15 现场双录AI业务流程自动化测试优化记录

## 优化背景
现场双录AI业务流程测试一直失败，问题集中在问答节点的"下一步"按钮点击和朗读节点的"完成录制"按钮点击。

## 主要问题及解决方案

### 问题1：问答节点"下一步"按钮点击失败

**原因分析**：
- AI播报过程中，话术内容会变色（蓝色=已读，白色=未读）
- 右下角的"下一步"按钮在播报过程中是灰色不可点击状态
- AI采集回答内容需要约4秒，4秒后"下一步"按钮才变为可点击

**解决方案**：
- 不再使用固定等待5秒后点击的方式
- 改为循环检测"下一步"按钮的enabled状态
- 只有当按钮enabled=True时才执行点击

```python
# 优化后的代码
btn_found = False
for attempt in range(60):
    try:
        next_btn = d(text="下一步")
        if next_btn.exists(timeout=1):
            if next_btn.info.get("enabled", False):
                next_btn.click()
                print(f"    第{cycle_num}次 - 已点击【下一步】(问答->朗读)")
                btn_found = True
                break
    except Exception:
        pass
    elapsed = attempt + 1
    print(f"    第{cycle_num}次 - '下一步'按钮不可点击，等待1秒...(已等待{elapsed}s)")
    time.sleep(1)
```

### 问题2：朗读节点"完成录制"按钮点击失败

**原因分析**：
- 按钮可能存在但由于UI状态问题导致点击失败
- 需要多钟定位策略尝试

**解决方案**：
- 方式1: text定位直接点击
- 方式2: XPath定位
- 方式3: 坐标定位（右下角区域）

```python
# 多种定位方式尝试点击"完成录制"
btn_clicked = False

# 方式1: text定位直接点击
try:
    if d(text="完成录制").exists(timeout=2):
        d(text="完成录制").click()
        print(f"    第{cycle_num}次 - 已点击【完成录制】(text方式)")
        btn_clicked = True
except Exception as e:
    print(f"    第{cycle_num}次 - text方式失败: {e}")

# 方式2: XPath定位
if not btn_clicked:
    try:
        finish_btn = d.xpath('//*[@text="完成录制"]')
        if finish_btn.exists(timeout=2):
            finish_btn.click()
            print(f"    第{cycle_num}次 - 已点击【完成录制】(xpath方式)")
            btn_clicked = True
    except Exception as e:
        print(f"    第{cycle_num}次 - xpath方式失败: {e}")

# 方式3: 坐标定位（右下角区域）
if not btn_clicked:
    try:
        width, height = d.window_size()
        click_x = int(width * 0.85)
        click_y = int(height * 0.85)
        d.click(click_x, click_y)
        print(f"    第{cycle_num}次 - 已点击【完成录制】(坐标方式: {click_x}, {click_y})")
        btn_clicked = True
    except Exception as e:
        print(f"    第{cycle_num}次 - 坐标方式失败: {e}")
```

### 问题3：业务办理完成后点击"返回"跳转到订单列表界面

**原因分析**：
- 点击"返回"后自动跳转到现场双录订单列表界面
- 不需要再点击"现场"菜单
- 需要直接点击"我的"菜单执行退出登录

**解决方案**：
- 删除Step 23（点击【现场】菜单）
- 点击"返回"后直接进入Step 23（点击【我的】菜单）
- 重新编号后续步骤

### 问题4：循环测试时App状态残留导致第2次测试失败

**原因分析**：
- 第1次测试完成后，App可能处于登录状态
- 第2次测试开始时，页面状态残留导致输入框定位失败

**解决方案**：
- 每次循环开始时调用 `d.app_stop()` 强制停止App
- 确保每次循环开始时App处于干净的启动状态

```python
# 1. 启动 App - 每次循环强制重启确保状态一致
print("\n[Step 1] 启动 App...")
d.app_stop('com.juphoon.hybridrecord')
time.sleep(2)
```
