# 2026-05-25 客户纯录制业务流程自动化测试优化记录

## 优化背景
客户纯录制业务流程测试失败，问题集中在录制结束后文件上传等待逻辑。

## 主要问题及解决方案

### 问题1：文件上传等待时间不确定

**原因分析**：
- 点击"业务完成"确认按钮后，文件开始上传，显示"文件上传中..."（转圈状态）
- 上传耗时是动态的，不是一个固定数字，需要等待服务器回调结果
- 回调完成后才弹出"文件上传成功"窗口，显示"确认"按钮

**解决方案**：
- 不再使用固定等待时间的方式
- 改为循环检测"确认"按钮是否出现
- 检测到"确认"按钮后立即点击
- 超时时间设为120秒，每10秒输出一次进度日志

```python
# 优化后的代码
print(f"    第{cycle_num}次 - 等待文件上传完成...")
upload_timeout = 120
upload_start = time.time()
upload_found = False
while time.time() - upload_start < upload_timeout:
    if d(text="确认").exists(timeout=3):
        d(text="确认").click()
        print(f"    第{cycle_num}次 - 已点击【确认】(文件上传成功)")
        upload_found = True
        break
    time.sleep(1)
    elapsed = int(time.time() - upload_start)
    if elapsed % 10 == 0:
        print(f"    第{cycle_num}次 - 还在等待文件上传...（已等待{elapsed}s）")
if not upload_found:
    print(f"    第{cycle_num}次 - 文件上传成功弹窗等待超时（{upload_timeout}s），截图诊断...")
    d.screenshot(f"customer_record_upload_timeout_{cycle_num}.png")
```
