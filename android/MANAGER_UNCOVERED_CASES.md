# Android 客户与客户经理补充自动化覆盖

客户经理场景由 `test_manager_uncovered_cases.py` 执行，客户场景由 `test_customer_h5_coverage.py` 执行。两个补充脚本均与 `test_jdualrecord_app.py` 的录制流程相互独立。

## 覆盖范围

- 登录校验：账号为空、非法/超长、不存在，密码为空、错误、大小写、首尾空格、显隐切换，验证码为空、错误、失效和刷新。
- 高级搜索：客户名称、证件号、下拉选项、单条件、多条件、模糊、无结果、空条件、条件保留、重置、重置后查询和返回。时间范围用例不纳入本套件。
- 远程双录：订单状态、产品类型、查询日期、组合筛选、无结果和重置。
- 现场双录：订单状态、产品类型、查询日期、组合筛选、无结果、重置和订单字段完整展示。

## 客户经理自动化场景

### 1. 登录校验

1. 打开智能双录 App，进入“客户经理登录”表单。
2. 账号留空，填写正确密码和验证码后登录；预期仍停留在登录页。
3. 分别输入非法或超长账号、不存在账号；预期登录请求被拦截。
4. 密码留空、输入错误密码、切换密码大小写；预期均不能进入订单首页。
5. 在正确密码前后加入空格并登录；记录系统对首尾空格的处理结果。
6. 点击密码显隐图标；预期密码可切换为明文，再次点击后恢复密文。
7. 验证码留空、输入错误验证码、使用刷新前的失效验证码；预期均停留在登录页。
8. 点击验证码图片刷新；预期页面响应且登录表单仍可操作。

### 2. 高级搜索

1. 使用客户经理账号登录，进入远程订单首页并打开“高级搜索”。
2. 不填写任何条件直接点击“查询”；预期返回远程订单列表。
3. 输入不存在的订单号 `NO_SUCH_ORDER_999999` 并查询；预期显示“暂无订单”或等价空状态。
4. 输入客户名称“郇伟”和客户证件号 `330212198508192621`；预期输入成功。
5. 分别操作记录类型、产品子类、产品名称和订单状态下拉项；预期选择器可正常打开、选择和关闭。
6. 只输入有效订单号并查询；预期返回目标订单。
7. 同时输入订单号、客户名称和客户证件号；预期组合查询返回目标订单。
8. 客户名称只输入“郇”进行模糊查询；预期仍能返回匹配订单。
9. 查询后再次打开高级搜索；预期查询条件状态正确保留。
10. 点击“重置”；预期条件被清空，重置后可再次查询。
11. 使用返回键退出高级搜索；预期回到订单列表。
12. 无论用例成功或失败，最后均尝试退出登录并返回手机桌面。

高级搜索不执行开始时间、结束时间范围用例。

### 3. 远程双录筛选

1. 使用客户经理账号登录；预期进入“远程双录”订单页面，页面显示订单状态、产品类型和查询日期筛选项。
2. 订单状态选择“待处理”并确认；预期顶部筛选项显示“待处理”。
3. 产品类型选择“理财”并确认；预期顶部筛选项显示“理财”。
4. 打开“查询日期”，选择两个不同日期；较早日期作为开始日期，较晚日期作为结束日期，然后点击“确认”。
5. 预期日期弹窗关闭并回到远程订单列表，订单状态、产品类型和日期组合筛选生效。
6. 打开全局搜索，先点击“重置”，再输入无效订单号 `NO_SUCH_ORDER_999999` 并查询；预期显示空结果。
7. 再次打开全局搜索并点击“重置”，输入有效订单号 `OD2099751229237243904` 后查询；预期返回对应远程订单。
8. 点击底部“我的”，执行“退出登录 → 确认”；预期返回登录页，随后按 Home 键返回手机桌面。

### 4. 现场双录筛选

1. 使用客户经理账号登录，从远程页面点击底部“现场”，进入现场双录订单列表。
2. 订单状态选择“待处理”，产品类型选择“理财”。
3. 查询日期选择不同的开始日期和结束日期并确认；预期组合筛选正常生效。
4. 打开全局搜索并先点击“重置”，输入无效订单号 `NO_SUCH_ORDER_999999`；预期显示空结果。
5. 再次打开全局搜索并重置，输入现场有效订单号 `OD2104818769953079296`；预期返回目标订单。
6. 校验订单卡片显示目标订单号、产品名称、开始时间、客户姓名和订单状态。
7. 点击“我的”退出登录，确认回到登录页后返回手机桌面。

## 客户自动化场景

客户角色使用账号证件号 `330212198508192621` 登录。筛选用例位于独立脚本 `test_customer_h5_coverage.py`，不会进入或修改现有录制主流程。

### 1. 登录校验

1. 打开 App 并进入“客户登录”表单。
2. 分别验证证件号为空、证件号格式非法、密码为空和验证码为空；预期均停留在登录页。
3. 填写密码后检查密文显示；点击显隐图标后应显示明文，再次点击后恢复密文。
4. 使用正确证件号、密码和验证码登录；预期进入客户订单首页。
5. 点击“我的”退出登录；预期返回客户登录页。

### 2. 远程双录筛选

1. 客户登录后点击底部“远程”，等待远程订单列表加载完成。
2. 订单状态选择“待处理”，产品类型选择“理财”。
3. 查询日期选择不同的开始日期和结束日期并确认；预期三个条件可组合筛选。
4. 打开全局搜索，点击“重置”，输入无效订单号 `NO_SUCH_ORDER_999999`；预期显示“暂无订单”。
5. 再次打开全局搜索并重置，输入有效订单号 `OD2099751229237243904`；预期返回目标远程订单。
6. 点击“我的”退出登录，并返回手机桌面。

### 3. 自助业务筛选

1. 客户登录后点击底部“自助”，等待自助订单列表加载完成。
2. 订单状态选择“待处理”，产品类型选择“理财”。
3. 选择不同的开始日期和结束日期并确认；预期组合筛选生效。
4. 全局搜索先重置，再查询无效订单号 `NO_SUCH_ORDER_999999`；预期显示空结果。
5. 再次重置并查询有效自助订单 `OD2102934122029674496`；预期返回目标订单。
6. 点击“我的”退出登录，并返回手机桌面。

### 4. 纯录制筛选

1. 客户登录后点击底部“纯录制”，等待纯录制订单列表加载完成。
2. 订单状态选择“待处理”，产品类型选择“理财”。
3. 选择不同的开始日期和结束日期并确认；预期组合筛选生效。
4. 全局搜索先重置，再查询无效订单号 `NO_SUCH_ORDER_999999`；预期显示空结果。
5. 再次重置并查询有效纯录制订单 `OD2100856414927859712`；预期返回目标订单。
6. 点击“我的”退出登录，并返回手机桌面。

### 5. 客户远程高级搜索回归

1. 在远程订单页依次选择订单状态“待处理”和产品类型“理财”。
2. 打开高级搜索，填写订单号、客户名称和客户证件号并检查输入结果。
3. 点击“重置”；预期订单号和客户名称被清空。
4. 输入不存在的订单号并查询；预期显示“暂无订单”。
5. 执行退出登录收尾。

## 执行命令

```powershell
python test_manager_uncovered_cases.py login-validation
python test_manager_uncovered_cases.py advanced-search
python test_manager_uncovered_cases.py remote-filters
python test_manager_uncovered_cases.py scene-filters
python test_manager_uncovered_cases.py all
```

客户角色的远程、自助和纯录制筛选使用独立脚本执行：

```powershell
python test_customer_h5_coverage.py remote-filters
python test_customer_h5_coverage.py self-service-filters
python test_customer_h5_coverage.py pure-record-filters
python test_customer_h5_coverage.py login-validation
python test_customer_h5_coverage.py remote-filter-search
```

三个客户筛选流程均覆盖订单状态、产品类型、日期范围、组合筛选、无效订单号、重置后有效订单号查询，以及退出登录后返回手机桌面。

客户经理截图输出到 `manager_uncovered_artifacts/`，客户角色截图输出到 `customer_h5_coverage_artifacts/`。任一套件断言失败时脚本返回非零退出码并保存失败现场。

## 环境说明

- 测试环境会放行任意四位数字验证码；错误/过期场景使用刷新后的非四位旧值覆盖客户端拒绝分支。真实验证码过期校验需在关闭测试验证码绕过的环境执行。
- 高级搜索不覆盖时间范围；远程和现场列表仍保留独立的“查询日期”筛选用例。
- 高级搜索套件执行结束后固定执行登出收尾；即使用例中途失败，也会尝试返回“我的”并退出登录。
- 新脚本不修改订单状态，也不会进入录制业务。
