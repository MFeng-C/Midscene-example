# 2026-06-10 iOS 纯录制业务流程测试优化记录

## 问题描述

iOS 客户纯录制业务流程测试在 Step 13（点击"返回"按钮）时失败，原因是"结束办理"弹窗的"确认"按钮无法点击。

## 问题分析

### 失败日志
```
[Step 13] 点击'返回'按钮...
    第1次 - 检测到结束办理弹窗(iter 0)
    第1次 - 原生Predicate点击'确认'成功
    ...
    第5次 - 原生遍历点击'确认'成功
    截图: error_step13_1.png
[第 1 次测试失败] 第1次 - 未找到'返回'按钮
```

### 根本原因

"结束办理"弹窗是 **H5 页面**，而脚本之前使用原生 iOS 定位方式（Predicate/遍历）尝试点击"确认"按钮，导致点击无法生效到 H5 弹窗上。

### 参考成功案例

脚本中其他弹窗使用 H5 `webview_click` 方式成功点击：

| 弹窗类型 | 点击方式 | 选择器 |
|---------|---------|--------|
| 文件上传成功弹窗 | `webview_click` | `.van-dialog__confirm` |
| 退出登录确认弹窗 | `webview_click` | `.van-dialog__confirm` |
| 结束办理弹窗（错误） | 原生iOS定位 | Predicate/遍历 |

## 解决方案

修改 `step13_click_return` 函数，将"结束办理"弹窗的确认按钮点击方式从原生 iOS 定位改为 H5 `webview_click` 方式：

```python
#修复前（错误方式）
try:
    buttons = driver.find_elements(AppiumBy.IOS_PREDICATE,
        "name == '确认' AND type == 'XCUIElementTypeButton'")
    for btn in buttons:
        if btn.is_displayed() and btn.is_enabled():
            btn.click()  # 原生点击对H5弹窗无效
except:
    pass

# 修复后（正确方式）
if webview_click(driver, [
    ("css", '.van-dialog__confirm'),
    ("css", 'button.van-dialog__confirm'),
    ("xpath", "//button[contains(text(),'确认')]"),
]):
    print(f"    第{cycle_num}次 - H5点击'确认'成功")
    time.sleep(0.5)
    screenshot(driver, f"step13_h5_confirm_{cycle_num}")
    break
```

## 技术要点

### H5 弹窗点击核心函数

```python
def webview_click(driver, selectors):
    """在 WebView 中点击元素"""
    if not switch_to_webview(driver):
        return False

    for selector in selectors:
        try:
            if selector[0] == "css":
                btn = driver.find_element(By.CSS_SELECTOR, selector[1])
            elif selector[0] == "xpath":
                btn = driver.find_element(By.XPATH, selector[1])

            if btn.is_displayed():
                driver.execute_script("arguments[0].click();", btn)
                switch_to_native(driver)
                return True
        except:
            continue

    switch_to_native(driver)
    return False
```

### iOS 弹窗类型判断

| 弹窗类型 | 特征 | 点击方式 |
|---------|------|---------|
| H5弹窗 |页面源码中有 `van-dialog` 等Vant组件类名 | `webview_click` + CSS |
| 原生iOS弹窗 | `mobile: alert` 可用 | `mobile: alert` accept |
