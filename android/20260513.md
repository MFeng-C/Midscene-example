## 优化的测试脚本

`android/test_jdualrecord_app.py` - Android UI 自动化测试脚本

## 优化内容

### 问题1：输入框元素定位优化
**之前**：使用坐标点击（如 `height * 0.3`），依赖屏幕比例，不可靠

**优化后**：使用 `resourceId` 精确定位输入框
- 工号输入框：`d(resourceId="van-field-4-input")`
- 密码输入框：`d(resourceId="van-field-5-input")`
- 验证码输入框：`d(resourceId="van-field-6-input")`

### 问题2：密码输入到工号输入框的问题
**原因**：使用坐标定位，工号和密码输入框的Y坐标接近，容易混淆

**解决**：使用 `clear_and_set_text` 函数 + `resourceId` 精确定位，确保输入到正确的字段

### 问题3：客户经理登录循环测试失败
**原因**：循环测试时 App 未完全重启，页面状态残留，导致输入框定位失败

**解决**：
1. 每次循环开始时调用 `d.app_stop()` 强制停止 App
2. 添加等待循环机制，等待登录表单加载完成后再输入
3. 等待超时后截图记录，便于排查问题

### 问题4：客户登录循环测试第2次失败
**原因**："客户登录"按钮未加载完成就执行点击

**解决**：添加等待循环机制，最多等待10秒，每0.5秒检查一次

### 测试流程说明

6. **点击登录按钮** → 登录成功后进入首页
7. **点击纯录制菜单** → 进入纯录制订单列表

15. **点击结束录制** → 点击"结束录制"按钮
16. **点击结束** → 点击右上角"结束"按钮
17. **确认弹窗** → 点击"确认"按钮
18. **点击返回** → 返回到菜单界面
19. **点击我的** → 进入个人中心
20. **点击退出登录** → 退出当前账号
21. **确认弹窗** → 点击"确认"按钮
22. **返回桌面** → 点击Home键回到手机桌面

### 等待登录表单加载
```python
print("    等待登录表单加载...")
form_timeout = 15
form_start = time.time()
while time.time() - form_start < form_timeout:
    if d(resourceId="van-field-4-input").exists:
        print("    登录表单已加载")
        break
    time.sleep(0.5)
else:
    d.screenshot(f"manager_form_timeout_{cycle_num}.png")
    print("    登录表单加载超时，继续尝试...")
```

### 清空并设置输入框文本
```python
def clear_and_set_text(d, element, text):
    """清空输入框并设置新文本"""
    element.click()
    time.sleep(0.3)
    element.clear_text()
    time.sleep(0.2)
    if element.get_text() != "":
        element.long_click()
        time.sleep(0.5)
        d(text="全选").click_exists(timeout=1)
        time.sleep(0.2)
    element.clear_text()
    element.set_text(text)
```
